Be specific about the hard parts, because the two stacks differ in ways
that are not the trajectory layer:
- **Token ids**: identical only if model, quantization, and sampling are
  identical. Under greedy/`temperature=0` they should be; under sampling
  they will not be. Decide now whether the golden run and the CP-09 run
  are greedy, and say so.
- **Logprobs**: uni-agent captures from `/v1/completions`; Polar captures

  predecessor measured prefill-vs-decode drift at mean|Δ| 0.0036) — state
  a tolerance rather than demanding equality.
- **Masks**: `loss_mask` semantics should match exactly (1 = sampled).
  This is the comparison that matters most and admits no tolerance.
- **Structure**: the predecessor stores `input_ids = prompts + responses`;
  Polar stores `prompt_ids` + `response_ids` separately. State the mapping.
- What a mismatch in each field would *mean* — which are Polar's fault,
  which are the platform's, which are ours.
