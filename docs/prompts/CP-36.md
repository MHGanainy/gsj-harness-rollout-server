# CP-36 — M11c: the stranger test, from nothing

You are executing CP-36 of `gsj-harness-rollout-server`. CP-34 built the
bootstrap; CP-35 built the readers. **This puts both in front of someone
who wasn't here** — and for the first time, nothing is gated on an
operator handing anything over: the wheel is on PyPI, both repos are
public, and the estate images are public on GHCR.

**The deliverable is the friction list.** CP-26 produced F-14 through
F-39 and they were its most valuable output. A run that works while a
stranger flounders is a failure.

**Needs a box with Docker and an inference endpoint.**

## The posture — read this twice
- **The demo repo's README is your only input.** Not the charter, not the
  reports, not `staging/`, not the library's `docs/` beyond what the
  README links.
- **A fresh environment**: new directory, new venv, nothing reused. And
  this time **nothing side-loaded** — `git clone` the demo from its
  public URL, `pip install gsj-harness-rollout-server` from PyPI,
  `docker pull` from GHCR. If any of those fails, that is the finding.
- **The endpoint is the one thing you bring.** CP-34's smoke used the
  reference stack; use it again if that is what you have, but record
  every place the walkthrough assumes it.
- **Write down the friction before fixing it.** Every use of out-of-band
  knowledge is a finding: what you knew, where it should have been
  written, what a real stranger would have done.
- **Do not improve the docs while running.** Log, finish, then fix.

## Step 3 — Read a trajectory, as a stranger
`read.py show`, `export`, `ls`, `quarantine`. The question is not whether
they run — it is **whether a stranger understands what they are looking
at**. CP-35's honest verdict was "readable, mostly because of the
collapse." Test that judgement against someone who doesn't already know
what the episode did.

And the residual CP-35 named: does a stranger judge the *system* by the
0.6B's degenerate output? Record your read.

## Step 4 — The preflight against a real endpoint
Run it. If your endpoint is the reference stack it should pass all six
probes — that is the control, not the test. Record what it would tell a
stranger whose endpoint differs, and whether that is actionable.

## Step 5 — The injected failures, second pass
**Only after Steps 2–4 are complete and recorded.**

- a config with the `/v1` suffix, and one with an unknown key

Keep these findings separate and say which pass each came from.
