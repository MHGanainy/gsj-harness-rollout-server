## Step 3 — Execute the comparison
Field by field, per `COMPARISON.md`'s procedure. Write a **comparison
table**, not prose: field · golden · collected · verdict · attribution.

The four that matter, in severity order:

1. **Masks — zero tolerance.** `loss_mask` semantics must match exactly:
   1 on engine-sampled spans, 0 elsewhere, boundaries aligned to turn
   structure. Compare per trace, and where the two stacks structure
   differently (`input_ids = prompts + responses` vs `prompt_ids` +
   `response_ids`), use the mapping the contract states. **A mask
   divergence attributable to Polar is a Path C trigger.**
2. **Token ids on the sampling-independent spans.** `prompt_ids` and the
   interstitial glue should be byte-identical — same model, same
   template, same corpus, same task. A divergence here is the
   retokenization class (A-1) and is the most serious thing this CP can
   find. Sampled ids are *not* compared across runs (the contract says
   so — different samples,.
3. **Logprobs by replay.** Teacher-force the golden's frozen `input_ids`
   through the same engine, compare against the golden's captured values
   within the contract's bounds (mean |Δ| ≤ 0.005, per-position |Δ| ≤
   0.05). Then the same for the collected trace. This validates *capture
   fidelity* on both sides rather than demanding two sampled runs agree.
4. **Structure and discipline.** Lengths consistent, `0.0` only at
   `mask==0`, no sentinel at `mask==1`, `finish_reason` sane. Note the
   MLX exact-`0.0`-at-`mask==1` platform artifact (CP-04, row 27) if it
   recurs — it is expected, and it is CP-10's problem to platform-condition,
   not a fidelity failure.

For every mismatch, state the attribution the contract prescribes:
**ours** (config, harness, builder), **Polar's** (capture, merging,
masking), or **the platform's** (engine numerics, quantization, MLX).
Attribution is the deliverable — an unattributed mismatch is an
unfinished comparison.

## Step 4 — The verdict
Answer plainlylar's trajectory reconstruction match the predecessor's?**

- **PASS** — masks exact, sampling-independent tokens identical, logprobs

Do not soften a FAIL and do not inflate a PASS. Two checkpoints of value
