## Step 1 — `prompt_source` (unblocks G1, row 9)
CP-11b measured the blocker precisely: the trace cannot identify which
skill card resolved, and without that no hash test can distinguish a skill
row from a free row that must pass n/a.

In `config.py:render_task_request`, add to `TaskRequest.metadata`:
`prompt_source` (`skill:<name>` | `free`) and, for skill sources, the
card's hash. Source it from the submit path — `cli.py` is frozen, so the
value must arrive through the config or the render ers; if it cannot, say so and record what would fix it rather than
lifting `cli.py`.

Then land **G1** in `checks.py`: hash the card bytes against
`skill_card_hash` when `prompt_source` names a skill; pass with an
explicit n/a finding-free path when it names `free`; fail closed
(`G1:missing_evidence:prompt_source`) when neither. Note the reserved-keys
rule CP-11 documented — don't collide with Polar's `setdefault` keys.
