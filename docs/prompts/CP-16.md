## Step 1 — Fix the trainer leg (wishlist item 10)
Law 6 says the trainer runs the same `checks` the receiver ran. CP-13a
measured that this is **non-functional from an installed wheel**: `pins/`
isn't package data, so the resolver points into site-packages and raises.

Decide and record:
- **Ship the pins as package data**, or **resolve them from a
  configurable path with a clear error when absent**, or both.
  Recommendation: **both** — a default set ships so  out of the box, and `GSJ_PINS_PATH` (or a `checks:` config key)
  overrides for an estate with its own approved sets. Note the tension:
  shipped pins are *this estate's* values, and a consumer with a
  different estate must override or they are validating against the wrong
  approved set. Make that loud — a mismatch should be an obvious error,
  not a silent pass.
- Where the resolver lives: `checks.py` owns it today; keep it there and
  keep the change to the seam.

Prove it: `pip install` the wheel into a scratch venv **outside every
repo**, import `checks`, and run `validate_session_result` on the real
CP-09′ callback body. It must work — that is the whole point.

## Step 4 — The three assertions
These are the CP's real content. Each gets a test that fails when removed.

1. **Mask before ratio.** Interstitial positions carry `0.0` placeholders,
   which read as probability 1.0. Any importance ratio computed without
   applying `loss_mask` first is silently garbage, and upstream says
   explicitly this is the consumer's responsibility. Assert it 
   — not a comment, a check that fails.
2. **Sentinel rejection.** `-9999.0` is finite and ≤ 0, so the naive
   discipline admits it. CP-02 established upstream has **no** value-level
   logprob validation anywhere. Reject at ingest.
3. **`checks` runs trainer-side.** The same `validate_session_result` the
   receiver ran, on what actually arrived. Assert it is called, not just
   available — CP-08's recording-wrapper pattern.

Plus the CP-09′ inheritance: any replay-style validation uses **this
estate's measured floor** (mean ≈ 0.005–0.008, per-position tail to
≈ 0.21), not the CP-18 anchor. If the bridge does no replay, say so and
record why.
