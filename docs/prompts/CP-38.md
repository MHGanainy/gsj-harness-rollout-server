## Step 2 — Serve Llama-3.1
The four legs, and the ones that differ from Qwen's are the point:

- **the tool-call parser** — Llama renders tool calls in its own JSON
 tool-call-parser llama3_json` is the candidate. **This is
  the leg most likely to produce a green-looking, tool-free episode**

- **the chat template** — CP-37 measured the official template

  came from; CP-37 found the same model name shipping two different

Record the serve argv verbatim. If it lands in `staging/serving/`, say

## Step 3 — Derive, and check the derivation against a live endpoint
CP-37's derivation has only ever run against Qwen. Run it against Llama
and report every value: the tail ids, the EOT id, the mode pair, what
was named-not-defaulted, r the template probe agrees with the
snapshot measurement CP-37 made offline.

**A disagreement between the offline snapshot and the live endpoint is a
finding**, and an important one — it would mean the served artifact
differs from the published one.

Then run the full preflight. Every row, verbatim. The rows that pass are
as informative as the ones that fail.

## Step 4 — Collect one episode
Through `bootstrap.py`'s own printed one-liner, on the demo's synthetic
corpus. Then, before anything else and in this order:

1. **`reconstruction_stats.chains_total`** — the number CP-37's probe
   predicts. If it is 1, the template property held under sampling, and
   that is the single most valuable measurement this CP can produce.
2. **the quarantine directory** — empty or not, and if not, which
   findings. A G6 finding means the derivation was wrong; a G7 means
   reconstruction split; anything else is new.
3. **the tool calls** — did the model actually call tools, and did the
   proxy parse them? Zerool calls with a green trace is the
   H-41 shape.

Then read it: `read.py show` and `export`. Does the transcript render? A
transcript is Qwen-tuned in its display heuristics (CP-37's item 15), so
say what degrades.

## Step 5 — The divergences, named and attributed
Every difference from a reference-stack episode, with attribution:
**the model's** (it behaves differently), **the estate's** (a serve leg),
**the demo's** (a derivation or a document), or **the library's** (a
Qwen assumption baked into `gsj_rollout/`).

The last category is the one that matters. **Do not fix it** — a library
change needs a budget raise and its own checkpoint. Name it precisely:
what assumption, where, what it costs, and what it would take.
