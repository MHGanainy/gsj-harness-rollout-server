#### What the spike surfaced that the charter did not anticipate

1. **pi streams unconditionally** — the single biggest fact: it makes P1
   inert (A-12), makes Polar's synthetic single-chunk SSE a load-bearing
   compatibility surface for pi (re-vendor tripwire on
   `gateway/server.py:771-810`), and means persisted requests can carry
   `stream: true` for a wire that sent `false` (never key a check on the
   persisted `stream` value).
2. **The workdir/setup chicken-and-egg trap**: `runtime.workdir` applies
   to every exec including the `setup()` that would create the dir;
   `docker exec -w <nonexistent>` fails before setup runs, and because
   the presets discard exec results the only symptom is "step 0 exited
   with code 127" with zero records. CP-07 rules: never point
   `runtime.workdir` at a harness-created dir; check `setup()` exec
   return codes loudly.
3. **Session-key binding is load-bearing**: capture attribution is
   `Authorization: Bearer` == session id; pi needs `$OPENAI_API_KEY`
   substituted into `models.json` `apiKey` or capture fragments into
   orphan sessions (fails loud downstream, but the episode is lost).
4. **The session temp dir is destroyed after the session** — pi's
   transcript survives only via a harness `postprocess()` download (or
   the CompletionWriter for proxy traffic). CP-07's provenance obligation
   (gap row 22) must ride one of those two exits.
5. **Gateway caches the imported harness module** — harness edits need a
   gateway restart; matters for CP-07 dev loop, documented on row 5.
6. **Deltas vs the predecessor's pi record**: 0.83.0 with
   `maxTokensField` unset transmits `max_completion_tokens: 8192` on
   every main-loop call (ADR-0027(g) recorded `maxTokens` as never
   transmitted — the field name and emission differ from that record);
   `chat_template_kwargs` carries a new `preserve_thinking: true`
   alongside `enable_thinking: false`; tool-result content can be a plain
   string, not only a content-part list (A-20 nuance).
7. **No new silent-degradation mode**: everything the spike hit fails
   loud (ERROR) or was a capture-fidelity caveat now documented; S1–S9
   stand unchanged.
