## The install decision (Step 3)

**ADR-0023: no `[verl]`/`[slime]` extras — a stated requirements file per
bridge plus one command.** Two hard blockers, either sufficient: pip
extras cannot express `--no-deps` (and verl-with-deps drags the
flash-attn-shaped closure the loop measurably runs without, F-12), and
PyPI rejects direct git URLs in published metadata — the extra would
re-open wishlist 17 as an error. The one command: `bash install.sh`
(venv → `requirements.txt` with the five unstated packages and the cu126
torch note → the locally built wheel, deliberately never index-first
while the PyPI name is unclaimed → verl `--no-deps` at
`bridge.VERL_SHA`). slime stays what it is: a 24.4 GB image, documented,
named in the run book as the alternative. The server leg's honesty is
inherited from the README's two-roles split and restated in the run book:
an estate, and `pip install` will never change that.
